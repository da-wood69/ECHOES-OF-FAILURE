ECHOES OF FAILURE
=================

Controls
--------
A / D or Left / Right: Move
Space, W, or Up: Jump
R: Clear echoes and restart

Core loop
---------
Touch a red hazard to fail deliberately. A cyan Echo Spring appears at
the last safe grounded position. Return to that echo and use it to reach
the next platform. Three intentional failures build the route to the
warm exit beacon.

Third-party assets
------------------
Robot art, light masks, and sound effects: Kenney (CC0).
The exact license texts are in ThirdPartyLicenses.

Build
-----
The build scene is Assets/EchoesOfFailure/Scenes/EchoesMain.unity.
It is added to Build Profiles automatically by EchoesProjectBuilder.
